# Contributing to Nexa

First off, thank you for considering contributing to Nexa!

## Getting Started

1. Fork the repository.
2. Clone your fork: `git clone https://github.com/brian2zz/nexa.git`
3. Create a branch: `git checkout -b feature/your-feature-name`
4. Install dependencies: `pip install -e .`

## Guidelines

- **Code Style**: Ensure your code follows the standard Python PEP 8 guidelines.
- **Testing**: Run tests before submitting a PR using `pytest tests -q`.
- **Commits**: Write clear and concise commit messages.

## Issues

If you find a bug, please create an issue with detailed steps on how to reproduce it.
